# Sơ đồ ERD (Dạng text - có thể vẽ bằng công cụ như Draw.io)

## Ký hiệu:
- [Entity] = Thực thể
- <Relationship> = Mối quan hệ
- {Attribute} = Thuộc tính
- *PK = Primary Key
- #FK = Foreign Key
